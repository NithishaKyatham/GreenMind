# GreenMind API Documentation

Interactive docs are auto-generated by FastAPI at:
- Swagger UI: `http://localhost:8000/docs`
- ReDoc: `http://localhost:8000/redoc`

This file is a human-readable summary. All endpoints are prefixed `/api`.

## Authentication
| Method | Path | Auth | Description |
|---|---|---|---|
| POST | `/auth/register` | No | Create a farmer account |
| POST | `/auth/login` | No | Returns `{access_token, refresh_token}` |
| POST | `/auth/refresh` | No (refresh token) | Rotate tokens |
| GET | `/auth/me` | Yes | Current user profile |
| POST | `/auth/logout` | Yes | Client-side token discard (stateless JWT) |

Send `Authorization: Bearer <access_token>` on all protected routes.

## Crops
| GET | `/crops` | Yes | List supported crops (seeded on first call) |

## Disease Detection
| POST | `/disease/predict` | Yes | `multipart/form-data`: `crop` (str, hint only — the model identifies the actual crop from the image), `image` (file, jpg/png, ≤8MB). Returns `PredictionOut`. |
| GET | `/disease/{prediction_id}` | Yes | Re-fetch a specific prediction |

`PredictionOut` fields:
- `disease`, `confidence`, `severity`, `recommendation`, `disclaimer` — as before
- `status`: `"confident"` (recommendation shown normally) | `"low_confidence"` (below `CONFIDENCE_THRESHOLD`, `disease` is `"Unable to confidently identify"`, `possible_disease` holds the model's unconfirmed guess, recommendation is a generic safe response) | `"fallback"` (no trained model loaded — clearly labeled, never presented as real)
- `crop_mismatch_note`: set when the user's selected crop doesn't match what the model identified in the image
- 38 supported classes total — see `ml/MODEL_INFO.md`

## History
| GET | `/history?crop=&q=&date_from=&date_to=&sort=latest\|oldest` | Yes | Search/filter/sort the user's predictions |

## Weather
| GET | `/weather?location=` | Yes | Live current + 5-day forecast (OpenWeatherMap). Returns `source: "unavailable"` with a message if no API key or the request fails — never fabricated. |

## Chatbot
| POST | `/chatbot/message` | Yes | Body: `{message, conversation_id?}`. Returns `{conversation_id, reply, mode, disclaimer}`. `mode` is `"llm"` or `"rule_based_fallback"`. |
| GET | `/chatbot/history/{conversation_id}` | Yes | Full thread for a conversation |

## Reports
| POST | `/reports/generate/{prediction_id}` | Yes | Generates a PDF, returns `{id, file_path, ...}` |
| GET | `/reports/download/{report_id}` | Yes | Streams the PDF file |

## Admin (requires `is_admin=true`)
| GET | `/admin/stats` | Yes | Total users/predictions, top diseases/crops |
| GET | `/admin/users` | Yes | User list with prediction counts (no password data) |
| GET | `/admin/predictions/recent` | Yes | Last 20 predictions across all users |

## System
| GET | `/health` | No | `{"status": "ok"}` liveness check |

## Error format
Validation errors: `422` with `{"detail": "...", "errors": [...]}`.
Unhandled server errors: `500` with `{"detail": "Internal server error. Please try again later."}` — never a raw stack trace.
